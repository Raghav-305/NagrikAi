# **App Name**: NagrikAI: Public Service CRM

## Core Features:

- Complaint Submission Interface: Provide a user-friendly form for citizens to submit complaints, including text description and optional image uploads.
- AI Complaint Analysis Tool: Utilize mock AI services to automatically classify complaint categories, assess sentiment (positive/negative), and determine urgency (low/medium/high) upon submission.
- Administrator Dashboard Overview: A centralized dashboard displaying key performance indicators such as total, open, and resolved complaints, along with complaint trends and summary departmental performance metrics using mock data.
- Interactive Complaint Management Table: An administrative panel featuring a searchable and filterable table to review and manage all complaints, showing status badges, priority color indicators, and core complaint details.
- Detailed Complaint View: A dedicated page for each complaint providing a comprehensive view of the complaint text, uploaded media, AI classification results, sentiment and urgency scores, assigned department, and an action timeline.
- Geospatial Complaint Visualization: An interactive map (Leaflet.js) to visualize complaint locations, with markers color-coded to reflect their urgency levels.
- Department Performance Analytics: Display charts and graphs showcasing department-specific performance metrics, such as average resolution times, current pending complaint workload, and resolution rates.

## Style Guidelines:

- Primary color: A deep, professional blue (#234988) to evoke trust, stability, and professionalism, reflecting governmental authority.
- Background color: A very light, near-white gray with a subtle blue tint (#F3F5F7), providing a clean, spacious, and highly readable backdrop for data-rich dashboards.
- Accent color: A vibrant, clear orange (#F89D4D) used to highlight urgent complaints, call-to-action buttons, or important notifications, offering energetic contrast against the primary blue.
- Headline and body text font: 'Inter' (sans-serif) for its modern, neutral, and highly legible design, ideal for both displaying data points and longer descriptive texts in a professional dashboard setting.
- Utilize minimalist, crisp line-art or subtly filled geometric icons throughout the interface, ensuring clarity and modern appeal consistent with a governmental digital service.
- Employ a modular and responsive grid layout. A fixed left sidebar will house primary navigation, complemented by a persistent top header for branding and global actions. The main content area will feature a dashboard style with various information cards, charts, and interactive tables, adapting seamlessly to different screen sizes.
- Implement subtle and purposeful animations for UI feedback, such as smooth transitions for data updates in charts, loading states, and hover effects on interactive elements, enhancing the user experience without distraction.
